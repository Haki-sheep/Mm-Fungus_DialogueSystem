# Mm-Fungus DialogueSystem — Unity 对话系统工程

用于接入 Fungus 并逐步开发对话功能的 Unity 工程。

当前状态：已建立 Unity 6 URP 基础工程，Fungus 包与对话功能待引入。

## 有什么用

- 作为 Fungus 对话系统的集成与开发工程。
- 用于后续搭建、调试和验证剧情对话流程。
- 功能清单与示例将在引入包后补充。

## 怎么用

1. 克隆本仓库到本地。
2. 使用 Unity Hub 添加仓库根目录，以 Unity **6000.3.26f1** 打开工程。
3. 等待 Unity 完成依赖解析与资源导入。
4. 打开 `Assets/Scenes/SampleScene.unity`，可运行当前基础场景。
5. Fungus 的导入、配置和对话使用步骤将在引入包后补充。
